# Nexa AI (Kotlin + Jetpack Compose)
1. In Android Studio create "Empty Activity (Compose)" project, package `com.nexa.ai`, minSdk 29.
2. Replace app/build.gradle.kts, AndroidManifest.xml and copy MainActivity.kt + FloatingService.kt into com/nexa/ai.
3. Run. Open Profile > Account & Security and paste your Gemini API key (aistudio.google.com).
